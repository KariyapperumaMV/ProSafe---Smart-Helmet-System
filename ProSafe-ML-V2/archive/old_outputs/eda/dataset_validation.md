# Dataset validation (ProSafe ML V2)

Generated by `src/eda.py`. W_002 is reported as **structure only** (counts, nulls, labels) - no feature values or distributions of the external test worker were examined before the model was frozen.

## Label check

Every file contains only `Safe`, `Warning`, `Critical`. **No `Uncertain` labels were found**, so the classifier is trained as a 3-class model; UNCERTAIN remains a data-quality outcome of the preprocessing gate.

## Baseline columns

`baseline_hr` and `baseline_body_temperature` are **absent** from all three files (verified). They are also on the forbidden-predictor list, so they could never enter `FEATURE_COLUMNS` even if re-added. Personalization is carried by `hr_deviation_bpm`, `hr_deviation_pct`, `body_temp_deviation_c`, `body_temp_deviation_pct`.
